# 中文整理界面验证记录

验证日期：2026-10-13。界面名称：书签归位（Bookmark Tidy）。

## 已实现

- 全页 MV3 工作区：左侧整理范围、整理整体 / 整理新增、分类粗细、全部书签搜索与锁定；右侧分类概览和名称 / 目标目录编辑表格。
- 预览只发送 `preview`，应用只发送当前 `planId`、逐项选中状态、新名称、目标目录 key 和人工决定保存选项。页面不调用书签写入 API。
- 目录范围下拉只列出可编辑的浏览器永久目录；整理新增仅在书签栏可选。范围、模式、粗细、锁定和规则变化使旧预览失效。
- 分类概览只统计选中项引用的目录；目录下拉使用后台完整候选列表，未引用的新分类不会由界面请求创建。
- 后台存在任意非空 journal 时禁止新预览和应用，提供明确的恢复撤回动作。应用 / 撤销 / 恢复失败后重新读取后台状态，防止部分写入后误用旧预览。
- 全局树搜索定位书签网址或目录路径。相同网址一起锁定，目录保护子树；管理员管理的节点和继承上级目录保护的节点无法通过子条目解锁。
- 域名 / 关键词自定义规则，JSON 导入、导出。导入只暂存，用户保存后生效；设置对象仅复制约定字段，不包含 API key。
- 完整 JSON 备份与浏览器可导入的 Netscape Bookmark HTML 备份分别导出、撤销上次整理、保留人工决定；完成提示仅在后台返回 `status: completed` 时显示。导出优先使用最近一次整理前的备份，没有保存的整理备份时使用当前书签；按钮说明和下载后提示均明确这一来源。HTML 使用共享的 escaping 导出函数；导入会新增条目，恢复名称和目录结构，不替换现有书签，不保留原 ID / 日期。
- 可折叠 AI 面板，完整 Chat Completions 地址、模型名称和可选密码输入。发送前逐项显示 `{id,title,hostname}`，勾选确认后才申请指定服务域名的可选权限。权限被拒绝时不请求 AI；请求结束或预览失效时清空密钥。
- 中文系统字体、浅灰蓝工作区与深蓝动作、可见键盘焦点、窄屏布局；没有远程脚本、字体、图像或遥测。

## 测试证据

执行：`node --test tests/ui.test.js`。

最近结果：16 个测试通过，0 失败，0 跳过。使用已有 bundled Playwright 和安装的 Chrome，无依赖安装。浏览器测试通过 localhost 静态页面和内存中的 `chrome.runtime.sendMessage` / permissions 适配器驱动真实 DOM；适配器只记录脱敏后的虚拟 key。

测试覆盖：

1. Manifest 必需 / 可选权限、模块后台、仅本地脚本及图标。
2. 生成预览不发送书签写入消息；取消项仍以未选中状态发送；编辑和保存人工决定明确传递。
3. 更改范围使旧计划不可应用。
4. 非书签栏范围自动选择整理整体并禁止整理新增。
5. 分类概览忽略未选中条目的目录。
6. 应用冲突后读取 pending journal，显示恢复入口并禁止再次应用。
7. 管理员与继承目录保护无法通过子条目解锁。
8. 导入暂存，不提前保存，保存前剔除 credential 字段。
9. 启动时检测未完成操作，恢复撤回后才允许新预览。
10. 全局树搜索锁定嵌套书签网址和目录路径。
11. AI 确认列表与原名 / 域名载荷完全一致；指定 origin 权限、清空 key、返回后仍不应用。
12. 拒绝域名权限不发送 AI 请求。
13. 本机 HTTP 服务可以不填 API key，并只申请本机 origin。
14. 桌面 / 窄屏不使页面横向溢出，应用动作可达，键盘焦点可见。
15. 可导入备份通过只读接口下载单个 HTML 文件，格式、名称、完整网址与 MIME 类型正确，不发送写入消息。

最初 RED：缺少 Manifest 与工作区，2 项按预期失败。后续补充测试先观察到分类计数、应用失败状态刷新、保护按钮、增量范围和可选 key 的失败，再修正实现并复测。

## 验证边界

这些结果证明页面交互、权限申请参数、数据确认和状态防护在 API 适配器下的行为。它们不等于真实书签写入验收，也不等于 Edge / Chrome 的独立临时 profile 端到端结果；真实浏览器书签 API、实际授权弹窗、同步冲突、应用 / 撤销由主任务单独验证。未测试真实云端 AI 服务，也未发送用户书签到云端。

运行时依赖为零。UI 测试使用已存在的 Playwright；可用 `PLAYWRIGHT_MODULE_PATH` 和 `BROWSER_EXECUTABLE` 指定测试环境中的工具，缺少工具时会明确报错，不会静默跳过。
